# Phase 4 Tool Priority Report

The current static inventory contains tool and commercial landing pages, but the repository does not establish that every named tool is functional. A tool is not treated as functional merely because a page has a calculator title or CTA. Each tool must be tested for inputs, formula, validation, output, accessibility, privacy, and methodology.

## Build first

1. **Automatic Renewal Date Calculator** — low legal and privacy risk when it calculates a user-entered date and displays assumptions; strong utility and shareability.
2. **Total Cost / Fee Comparison Calculator** — useful for public price comparisons when users enter values; no HiddenFeeAI dependency; can produce a printable result.

## Defer

Hidden-fee risk score, savings calculator, AI contract score explainer, medical-billing estimates, industry benchmarks, and any tool implying detection accuracy or likely savings remain gated by verified methodology and owner confirmation.

## Requirements

Every approved tool needs labeled inputs, keyboard access, input constraints, formula disclosure, examples, reset behavior, accessible output, printable/shareable result, no sensitive data collection by default, a limitations note, source/methodology link, and tests at mobile widths.
