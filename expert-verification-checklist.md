# Expert Verification Checklist

- [ ] Person agreed to attribution and review scope.
- [ ] Identity and current role verified.
- [ ] Relevant credentials verified through a legitimate source.
- [ ] Conflict and compensation disclosure recorded.
- [ ] Page scope and sources supplied.
- [ ] Review date and renewal date recorded.
- [ ] Public profile contains only supported details.
- [ ] Person schema added only if visible profile supports it.
- [ ] No claim of endorsement beyond the actual review.
