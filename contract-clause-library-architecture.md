# Public Contract-Clause Library Architecture

The library will be one canonical index with a small number of reviewed entries. Each entry uses the same fields: definition, short original illustrative example, why it may matter, legitimate purpose, possible risks, questions, document types, industries, jurisdiction limits, review trigger, related hidden-fee categories, related pages, official sources, detection limits, last reviewed, and corrections path.

Initial entries: automatic renewal, price escalation, unilateral modification, termination/cancellation, auto-billing authorization, and limitation of liability. Mandatory arbitration, class-action waiver, indemnification, warranty disclaimer, personal guarantee, governing law, venue, late fees, collection costs, acceleration, assignment, exclusivity, data-use permission, and refund restrictions remain planned until each has a source and review owner.

Use short original examples, never copied contract passages. The library is educational and does not determine that a clause is unfair, abusive, or unlawful.
